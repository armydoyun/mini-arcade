# v0.6.0 · Logic Collection · 구현과 검증

기준일: 2026-11-01. v0.5.0 소스를 기준으로 게임 4종을 추가했다. 전체 40종, 혼자 하기 28종·둘이 하기 13종이며 골프는 두 필터에 함께 포함한다. HTML/CSS/JS와 네이티브 ESM, PC 키보드·마우스, 외부 라이브러리·자산·서버 API 없음이라는 기준을 유지한다.

## 이번 범위

레이저 반사 퍼즐·만칼라·스도쿠·파이프 연결을 구현했다. 폭탄 미로 대전·연쇄 낙하 퍼즐·배구·핀볼은 실시간 반응·물리·대전 밸런스의 실기 검증이 더 필요해 보류했다. 이 문서의 검사는 구현한 규칙과 경계를 확인하며 모든 환경에서의 무결함을 보증하는 의미는 아니다.

## 네 게임의 동작

| 게임 | 구현 |
|---|---|
| 레이저 반사 퍼즐 | 12판, 2~6개의 거울, 다중 목표와 분광기. 셀/방향 상태를 한 번만 방문해 분기·중첩·순환에서도 유한하게 끝난다. 모든 목표가 켜져야 완료한다. 모든 거울 배치 전수 검사로 유일해와 시작 최소 회전을 확인했다. |
| 만칼라 | 로컬 2인 칼라 규칙. 칸마다 씨앗 4개/3개 모드, 자기 저장소 포함·상대 저장소 건너뛰기, 추가 턴, 빈 자기 칸과 맞은편 포획, 한쪽 소진 시 전체 정산. 선공 교환 규칙은 사용하지 않는다. |
| 스도쿠 | 9×9, 고정 숫자 42·34·28개인 문제 각 6개. 총 18개를 생성하고 별도 풀이로 유일해를 확인했다. 숫자·메모·삭제·관련 칸·중복 표시·동료 메모 정리·전체 Undo·첫 편집부터의 기록 시간을 제공한다. 난이도 구분은 고정 숫자 수 기준이다. |
| 파이프 연결 | 4×4 3판·5×5 5판·6×6 4판. 양방향 90도 회전, 고정 전원, 연결 영역과 열린 포트 표시. 전체 칸 연결과 모든 포트 맞물림을 함께 요구한다. 별도 제약 탐색으로 유일한 연결 배치와 최소 회전을 확인했다. |

신규 퍼즐은 회전/입력 상태를 자유롭게 되돌릴 수 있다. 힌트는 연습 기록으로 구분하며 Undo로 자격을 회복할 수 없다. 레이저·파이프는 회전 수, 스도쿠는 풀이 시간을 낮을수록 좋은 기록으로 저장한다. 새 퍼즐 42개는 완료·보조 완료·다음 미완료 이동을 공유하고 기존 완료 키를 유지한다.

## 조작과 표현

- 거울과 파이프의 DOM 노드를 유지해 회전 전환이 실제로 이어지게 했다. 파이프의 누적 회전 방향도 Undo 상태에 포함한다.
- 스도쿠는 고정 숫자를 보호하고 중복 규칙만 표시한다. 일반 입력을 정답과 대조하지 않는다. 메모를 자동 제거한 작업도 함께 되돌린다. 숫자 버튼과 편집 도구를 두 줄로 정렬하고 메모 ON/OFF의 문구·툴팁·눌림 상태를 함께 갱신한다.
- 만칼라는 씨앗을 나눠 담는 동안 추가 입력과 Undo를 잠근다. 손에 남은 수를 표시해 보드와 손의 합을 추적할 수 있다. 예약 시각은 한 수의 시작점을 기준으로 해 짧은 대기 오차의 누적을 막는다. 포획한 칸과 저장소를 강조하고 Enter 자동 반복으로 다음 수를 실행하지 않는다.
- 신규 보드들은 물리 반응 제한 시간이 없어 낮은 그리기 빈도만으로 입력을 차단하지 않는 정책을 사용한다. 명시적 일시정지·포커스 상실·페이지 숨김 처리는 계속 적용한다. 기존 게임과 메모리 미리보기의 긴 프레임 중단 보호는 유지한다.
- 새 SVG 4개는 기존 필드·둥근 선·파스텔 색을 따른다. 만칼라는 실제 6칸씩 두 줄, 스도쿠는 9×9/3×3 구분, 레이저는 거울 각도와 빛의 꺾임을 맞췄다.

새 검사에는 다음이 포함된다.

- 레이저 12판의 모든 방향 배치를 별도 벡터 광선 모델과 비교. 유일해·최소 회전·고정 도형·순환 종료·Undo·연습 자격과 실제 클릭 완주.
- 파이프 12판의 독립 제약 탐색, 경계 포트·단절 회로·전부 연결됐지만 열린 끝이 남은 경우, 양방향 최소 회전·고정 도형·Undo·실제 좌우 클릭 완주.
- 스도쿠 18문제의 별도 집합 기반 탐색과 실행 풀이 비교, 27개 집 검증, 모든 문제의 실제 숫자 입력 완주. 고정 숫자·중복·메모 토글·자동 정리 복원·일시정지·힌트 자격·완료 시각의 분 경계 고정.
- 만칼라 별도 순환 순서 모델과 교차 비교, 30개 합법 경기의 씨앗 보존·전체 종료, 포획/빈 맞은편/종료 정산/추가 턴 우선순위, 배분 중 잠금·손 수치·pause·Undo·키 반복·전체 키보드 경기·모션 줄이기.
- 앱의 진행 보호, 새 완료 키·기존 완료 보존, 보조 완료·최고 기록 제외, 다음 미완료 포커스, 모드별 대전 기록·NEW 필터.

실행 파일·상대 정적 import·외부 요청 없음·SVG XML도 별도로 확인했다. 용량은 [SIZE.md](SIZE.md)에 있다.

## 브라우저 확인과 한계

Chrome에서 레이저 첫 판을 2회, 파이프 첫 판을 좌우 클릭 9회로 완료했고 기록·다음 미완료 연결을 확인했다. 스도쿠는 메모·Undo 후 빈칸 39개를 실제 키보드로 채워 완료와 기록을 확인했다. 만칼라는 4개 씨앗 배분, 자기 저장소 착지에 따른 추가 턴, 전체 Undo와 진행 종료 확인창을 확인했다.

960×720에서 스도쿠 숫자·두 줄 도구, 6×6 파이프, 만칼라의 보드·HUD·도구를 확인했다. 스도쿠는 1024×768·1920×1080에서도 측정했고, 1280×720에서 홈·새 SVG와 레이저 보드를 확인했다. 확인 상태에서 가로 넘침이 없으며 긴 설명은 사이드바에서 스크롤한다.

현재 검증 브라우저의 독립 측정기는 약 1fps·최대 약 1,017ms 간격으로 관측된다. 신규 정적 보드의 실제 입력·완주 확인은 가능했으나 60fps 회전·씨앗 이동의 시각적 매끄러움은 이 환경에서 확정하지 않는다. 물리 기반 보류 게임을 구현했다고 표시하지 않는다. 여러 PC의 장시간 플레이와 최종 단일 HTML 번들은 별도 확인 대상이다.
