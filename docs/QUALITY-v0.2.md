## 공통

- 액션·실시간 대전·기억 게임은 준비 화면에서 시작한다. 시작 전에는 게임 시간이 진행하지 않으며, 시작 키가 곧바로 게임 동작으로 중복 적용되지 않는다.
- 모드와 문제의 기록을 분리한다. 힌트·싱글 되돌리기·둘러보기는 연습으로 표시하고 최고 기록을 덮지 않는다. 실패한 스프린트는 완주 시간 기록을 갱신하지 않는다.
- 결과에서 보드를 다시 볼 수 있다. F 집중 모드는 사이드바와 주변 UI를 접고, 홈으로 돌아오면 원래 배치로 복원한다.
- DOM 보드의 방향키 탐색, 포커스, 대비를 보강했다. 상·하 경계에서 다른 열로 이동하지 않게 했다.
- 파티클은 최대 180개, 점수 라벨은 10개다. 충돌은 이펙트와 분리하며 동작 줄이기 설정은 비필수 파티클을 줄인다.
- 게임 전환 시 입력·RAF·지연 동작·ResizeObserver를 정리한다. 효과음은 종료 후 오디오 노드 연결을 해제한다.

## 검증과 한계

규칙 검사 9,890건, 실행·통합 검사 724건을 통과했다. 원본 용량은 SIZE.md의 실측치를 따른다.

- 순수 규칙 검사와 실제 모듈 실행·입력·지연 작업·종료 검사, 저장 실패와 기록 분리 검사를 포함했다.
- 모든 모드 초기화, 24문제 완주, Lights Out 해답, Flood It 제한 내 완주, Simon 패턴, 카드 짝맞추기 완주를 검사했다.
- 주요 액션은 긴 시뮬레이션에서도 그리기 좌표의 유한성과 결과 중복 방지를 확인했다. 이 검사는 실제 GPU/브라우저 성능 측정을 대신하지 않는다.
- 브라우저에서 28종 진입·시작·재시작, 로직 퍼즐의 실제 마우스 드래그와 묶음 되돌리기, 연습 완료→다음 문제, 테트리스 홀드·스프린트 유지·집중 모드 복원을 확인했다.
- 장시간 난이도·재미의 평가는 실제 플레이와 두 사람의 물리 키보드 대전으로 더 조정해야 한다. 테트리스 회전 보정은 이 프로젝트의 간단한 벽차기이며 정식 Guideline SRS 전체를 구현했다고 주장하지 않는다.
