# v0.5.0 · Play Together · 변경과 검증

측정일: 2026-11-01. v0.4 소스에서 이어서 개발했다. 순수 HTML/CSS/JS, 정적 ES Module, PC 키보드·마우스 기준을 유지한다. 게임은 32종에서 36종이 됐다. 혼자 하기 25종과 둘이 하기 12종은 골프를 공통으로 포함한다.

## 추가한 게임

| 게임 | 동작과 완성도 |
|---|---|
| 땅따먹기 | 그리기를 켜고 안전 영역을 벗어난 뒤 돌아오면 닫힌 선을 확정한다. 빛이 속한 미점령 연결 성분은 남기고 나머지를 점령한다. 선 교차와 빛의 이동 구간 접촉을 검사하며, 기회 3개·잠깐의 재시작 보호·70/75% 목표를 제공한다. 이동은 격자 판정과 보간 표현을 분리한다. |
| 버블 슈터 | 3/4/5색 모드, 육각 격자, 3개 연결 제거와 천장에서 끊긴 묶음 낙하를 구현했다. 조준선과 실제 발사는 같은 연속 충돌·반사 함수를 쓴다. 부착 후보를 빈 이웃으로 제한하고 남은 색만 제공한다. 5회 연속 실패하면 한 줄 내려오며 행 위상을 바꿔 기존 x좌표를 유지한다. 하강·낙하 연출 중 입력은 잠근다. |
| 미니 골프 | 독자 코스 9개, 솔로 총 타수와 2인 교대 모드를 제공한다. 당겨서 퍼팅하거나 각도·힘을 키보드로 조정한다. 지수 마찰을 적분하고 벽 반사 후 남은 시간, 저속 홀 진입, 물 1벌타·샷 출발점 복귀를 처리한다. 완주한 사람은 기다리고 홀당 12타로 끝낼 수 있다. 코스 사이에는 준비 화면을 둔다. |
| Switch Duo | 12개 고정 스테이지에 발판·토글 스위치·2채널 문·역할별 바닥·서로 다른 출구를 구성했다. 같은 틱의 두 이동을 함께 판정해 같은 목적지는 취소하고 자리 교환은 허용한다. 문 위 점유는 닫힘을 막는다. 두 사람이 모두 자기 출구에 있어야 완료하며 개별 걸음 합을 기록한다. 공동 되돌리기는 상태·회로·입력을 함께 복원한다. |

골프의 PAR는 기준 타수다. 샷 인증은 실제 완료 경로를 확인하는 것이며 최소 타수 증명은 아니다. 협동 풀이 역시 완료 가능성을 확인하며 최단 공동 해답을 주장하지 않는다. 버블의 모든 무작위 판이 완전 제거 가능하다고 보장하지 않는다.

## 기존 게임에서 고친 경계

- 일시정지나 Undo로 해제된 키는 자동 반복 keydown만으로 다시 활성화하지 않는다. 새 keydown이 있어야 이동한다.
- 소코반 Undo는 예약 방향·자동 걷기·마지막 키·유지 입력을 함께 취소한다. 되돌린 직후 다시 움직이던 경우를 막는다.
- 탱크는 탄환의 남은 수명만큼만 추적한다. 프레임 중간에 수명이 끝날 때 구간 시간을 원래 dt 비율로 환산해 움직이는 플레이어와 비교한다. 여섯 번째 반사 이후 구간은 피격 검사에서 제외한다.
- 소코반 20개 최소 밀기·실제 키 입력 완주, 블록 완전 제거·복원, 길막기 합법 경로·장벽·완주, 탱크 반사·재장전·자기 피격·동시 격파·3승 검사를 모두 다시 실행했다.

## 공통 UX와 표현

새 카드 4개를 맨 앞에 정렬하고 NEW 필터에 묶었다. 게임 SVG 4개는 기존의 140×112 필드·둥근 선·파스텔 색과 동일한 체계를 사용한다. 36개 게임 그림과 공통 아이콘 13개의 XML을 검사했다. 버블은 색과 기호, 협동 말과 출구는 색과 번호를 함께 쓴다.

골프의 모드별 인원과 기록 종류를 카탈로그에서 정의한다. 홈의 1–2P 표시, 인원 필터, 게임 헤더, 결과와 재시작 문구에 반영한다. 골프 solo는 총 타수가 낮을수록 좋은 기록이며 duel은 승패만 저장한다. 협동은 대결 대신 함께 다시 하기로 표시하고 완료·다음 미완료 스테이지를 제공한다. 기존 v3 기록·즐겨찾기·설정·완료 키는 유지한다.

골프·협동의 진행 중 이동도 초기화 확인을 거친다. 코스 사이 준비 화면에서 이동을 취소하면 게임 포커스를 복원한다. 골프 드래그 취소는 원래 조준과 힘으로 돌아가고 샷을 소비하지 않는다. 겹쳐 출발한 공은 현재 플레이어의 공을 앞에 그린다. 완료 후 누적 타수를 중복 합산하지 않는다.

버블 하강과 협동 문 열림을 부드럽게 전환한다. 모션 줄이기에서는 버블의 추가 연출 대기를 생략하고 낙하 입자를 생략한다. CSS 전환과 공통 효과도 같은 설정을 따른다.

수명주기 검사는 36종과 등록 모드를 실행하고 약 570만 번의 Canvas 호출 인자가 유한한지 확인한다. 조건 수는 재미 점수나 실제 플레이 횟수를 뜻하지 않는다.

확장 검사는 다음 결과를 포함한다.

- 땅따먹기: 빛이 양쪽에 있을 때의 점령 보존, 완전한 실제 입력 경기에서 70% 이상 점령, 세 번의 선 교차로 생명 소진·단일 종료.
- 버블: 행 위상별 이웃과 실제 좌표 일치, 부착 덮어쓰기 거부, 연결 제거·고립 낙하, 천장 삽입 시 x 보존, 조준선과 분할 이동의 반사 후 도착 일치. 고정 시드는 실제 조준 21회로 완전 제거했고, 잘못된 연속 발사로 천장 하강·패배도 확인했다.
- 협동: 12개 스테이지 풀이 탐색 후 키보드와 마우스 입력을 섞어 전부 재생. 동시 이동·충돌·자리 교환·역할 바닥·문 점유·회로·공동 Undo·정확한 기록 키를 검사했다.
- 골프: 성공 샷 인증을 솔로와 2인 9홀 전체에서 실제 드래그로 재생했다. 솔로 12타와 2인 동률, 물 1벌타, 드래그 취소, 홀 전환·차례·끝난 공 대기·단일 종료를 검사했다. 마찰 이동은 60/30/15/10fps 간격에서 수치가 일치한다.
- 앱: 모드별 골프 기록, 협동 완료·다음 스테이지, 함께 다시 문구, 25/12/4 인원·신규 필터, 준비 화면에서 이동 취소·포커스 복원을 검사했다.

추가 정적 확인은 실행 파일 46개, 상대 경로 정적 import, SVG 49개 XML, 외부 실행 자산·네트워크 요청 없음, 실행 원본 1,000,000 B 미만이다. 자세한 바이트 표는 [SIZE.md](SIZE.md)에 있다.

## 실제 브라우저 확인과 한계

Chrome에서 새 카드·SVG·준비 화면·모드 선택·인원 표시와 땅따먹기 시작/자동 일시정지를 확인했다. 960×720의 버블·2인 골프·협동, 1024×768과 1920×1080의 13열 협동 보드, 1280×720 홈·보드 배치를 측정했다. 확인한 상태에서 가로 넘침이 없고 보드·HUD·도구가 창 안에 들어온다. 긴 설명은 사이드바 안에서 스크롤한다.

이 브라우저는 게임과 독립된 측정기에서도 약 1fps·최대 간격 약 1,017ms로 관측됐다. 긴 프레임 중단에 대한 제품의 자동 일시정지가 실제 작동했다. 따라서 이 환경에서 지속적인 실시간 플레이나 60fps 애니메이션 체감을 확인했다고 주장하지 않는다. 위 모의 프레임 검사는 로직의 시간 처리와 위치를 검사한 것이다.

일반 PC의 연속 플레이 감각·장시간 밸런스·물리 키보드의 동시 입력은 추가 실기 확인 대상이다. 최종 단일 HTML은 사용자가 번들링한 뒤 별도로 실행·용량·외부 요청을 확인해야 한다. 이 패키지는 검증한 ESM 개발 소스다.
