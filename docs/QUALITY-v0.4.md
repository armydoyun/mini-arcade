# MINI ARCADE v0.4 · Arcade Expansion

기준: MINI-ARCADE v0.3.0 PC ESM 소스. 2026-11-01.

32종: 혼자 하는 게임 22종, 한 기기에서 함께 하는 대전 10종. 실행 코드는 HTML·CSS·JavaScript와 정적 ES Module만 사용한다. 게임별 진입 모듈을 유지하고 추가 자산이나 외부 패키지를 요구하지 않는다.

## 소코반

독자적으로 구성한 창고 20개를 제공한다. 처음 두 문제는 한 번 밀기와 돌아서 밀기이며, 이후 여러 상자·통로·목표 배치를 사용한다. 각 문제를 독립적인 밀기 단위 BFS로 풀어 최소 밀기 1~13회를 확인했고, 검증된 경로를 실제 게임 키 입력으로 재생했다.

- 이동·상자 밀기는 105ms 전환을 사용한다. 이동 중 들어온 방향 하나를 보관하고, 키를 유지하면 정해진 간격으로 반복한다.
- 바닥 클릭은 상자를 통과하지 않는 걷기 경로를 찾는다. 직접 방향을 누르거나 일시정지하면 자동 걷기를 취소한다.
- 상자 두 개를 밀거나 벽으로 미는 입력을 거부한다. 목표가 아닌 고정 모서리에 들어간 상자는 경고하고 되돌리기를 안내한다. 경고가 모든 교착 상태를 판정한다고 주장하지 않는다.
- 목표에 놓인 상자는 색·짧은 강조·효과음으로 확인한다. 마지막 이동의 전환 뒤에 결과를 표시한다.
- 되돌리기는 횟수 제한과 기록 불이익이 없다. 1,502수의 이동을 전부 되돌리는 조건도 확인했다.
- 밀기가 적은 기록, 같으면 이동이 적은 기록을 우선한다. 스테이지별 완료·기록·다음 미완료 이동을 제공한다.

## 블록 묶음 지우기

3색 10×8, 4색 12×10, 5색 14×10 모드를 제공한다. 같은 색의 변으로 연결된 두 개 이상을 선택하고 한 번 더 눌러 제거한다. 색마다 모양 기호를 함께 사용한다.

- 선택 범위·개수·예상 점수를 보여준다. 제거 점수는 `(묶음 크기 - 1)²`, 전부 제거하면 1,000점을 추가한다.
- 제거 120ms → 수직 낙하 → 필요한 경우 열 당김 순으로 진행한다. 이동하는 블록의 DOM을 유지하며 transform을 바꾼다. 전체 대기는 약 330~500ms다.
- 전환 중 추가 제거를 막고 키보드 진입점 하나를 유지한다. 게임 진입 직후 방향키로 탐색할 수 있고 실제 포커스와 Enter의 대상이 일치한다.
- Undo는 판·점수·제거 수를 함께 복원하고 연습으로 표시한다. R과 N은 같은 시드 재시작과 새 판을 구분한다. 기록은 같은 문제끼리 비교한다.
- 더 지울 묶음이 없으면 정산한다. 모든 난수 판의 완전 제거 가능성을 보장하는 모드는 아니다. 고립 블록이 남아도 획득 점수는 기록할 수 있다.

## 길막기 대전

9×9 보드에서 P1은 위, P2는 아래쪽 끝으로 먼저 이동하면 승리한다. 한 턴에 말을 움직이거나 장벽 하나를 놓는다. 각자 10개를 사용한다.

- 합법 이동 칸, 플레이어 차례와 목표 방향을 표시한다. 말 이동은 140ms 전환을 사용한다.
- 가로·세로 장벽을 마우스 또는 키보드로 미리 보고 놓는다. 셀·테두리·장벽 좌표를 맞추며 잘못된 미리보기는 줄무늬로 구분한다.
- 장벽 겹침·부분 중복·교차를 거부한다. 배치 후 두 사람 모두 목표에 도달할 경로가 남아야 한다.
- 마주 선 상대를 뛰어넘는다. 뒤가 장벽 또는 보드 가장자리로 막혔을 때만 옆으로 돌아가는 이동을 허용한다.
- 셀 이름에 도착선·막힌 방향을 제공한다. 한 수 복원은 말·장벽·장벽 재고·차례를 함께 되돌린다.
- 마지막 이동이 끝난 뒤 결과를 표시하고 보드 살펴보기를 지원한다.

## 반사 탄환 탱크 대전

P1은 WASD+Space, P2는 방향키+Enter를 사용한다. 방향 입력에 따라 가속·감속하고 포탑은 짧은 각도로 부드럽게 회전한다. 현재 포탑 방향으로 발사하며 점선은 가까운 반사 경로를 보여준다.

- 탄창 3발, 발사 간격 0.3초, 빈 탄창은 1.25초 자동 재장전이다. 잔탄과 재장전 진행을 HUD·차체 주변에 표시한다.
- 탄환은 이동 구간을 따라 벽 충돌·반사를 계산한다. 벽 충돌 뒤 남은 이동 시간도 처리하며 조준선과 발사 경로에 같은 반사 계산을 사용한다.
- 상대에게는 직접탄도 유효하고 자신에게는 한 번 이상 반사된 탄환이 유효하다. 같은 틱의 동시 격파는 무승부다.
- 벽 가까이에서는 포신의 시각적 길이를 줄인다. 포구 경로가 막히면 탄을 소비하지 않고 안내한다.
- 탄환 수명·반사 횟수·궤적 길이와 공통 파티클 수를 제한한다. 판정은 시각 효과에 의존하지 않는다.
- 라운드 60초, 시간 초과는 무승부다. 먼저 3승하면 종료한다. 라운드 사이에는 두 사람이 준비 후 다시 시작한다.
- 교차 엄폐·기둥·중앙 통로의 대칭 경기장 3개를 사용한다. 순환 모드에서는 라운드에 따라 바뀐다.
- 준비 카운트다운의 남은 시간을 정확히 소비하도록 처리해 모의 60/30/15/10fps에서 이동 위치·활성 시간이 일치한다.

## 공통 화면·구조

신규 카드 4개를 첫 줄에 모으고 NEW 표시와 ‘새 게임 4’ 필터를 제공한다. 검색·인원·장르·즐겨찾기와 함께 사용할 수 있다. 기존 파스텔 말·어두운 필드·둥근 도형·아이콘 체계를 따른 새 SVG 4개를 추가했다.

PC의 남은 높이를 이용한 보드 배치를 유지하고 긴 규칙은 사이드바 안에서 스크롤한다. 사이드바 높이를 조정해 720px 높이에서 바깥 스크롤이 생기던 작은 넘침을 없앴다. 모션 줄이기 판정을 공통 함수로 모아 새 연출의 대기도 생략한다.

게임은 4개 모듈을 추가하고 순수 판정은 기존 rules.js, 문제 데이터는 puzzles.js에 둔다. 공통 완료 처리에는 메타데이터를 사용한다. 기존 로직 퍼즐 완료·v3 점수·설정·즐겨찾기를 유지한다. 소코반 완료와 기존 로직 완료는 키를 분리하고 손상된 완료 값과 동률 값을 정상화한다.

## 브라우저 확인과 한계

Chrome에서 새 카드·필터·로고, 소코반 첫 완료·기록·다음 스테이지, 마지막 창고의 작은 창 배치, 블록 13개 선택→144점·107개 잔여·단일 Tab 진입, 마우스 장벽 배치와 같은 교차점의 배치 거부를 확인했다. 작은 창의 보드·HUD·도구와 사이드바 범위도 측정했다.

이 검증 환경은 게임과 독립된 RAF 측정 화면에서도 약 1fps·약 1,017ms 간격이 관측됐다. 활성·가시 상태를 확인한 별도 탭에서도 같았다. 제품은 긴 프레임 중단을 자동 일시정지하므로, 여기서 지속적인 실시간 대전이나 60fps 애니메이션 체감이 검증됐다고 주장하지 않는다. 모의 간격 검사는 게임 로직의 시간 분할과 위치를 확인한 것이다.

실제 PC에서의 연속 플레이·여러 키보드의 동시 입력·브라우저별 모션·장시간 밸런스는 추가 확인 대상이다. 최종 단일 HTML은 사용자가 번들링한 뒤 별도로 실행·외부 요청·용량을 확인해야 한다.
