# 재미 연구와 개선 · v0.8

40종을 직접 실행해 보며 “다시 하고 싶게 만드는 요소”를 기준으로 살폈습니다. 판단 기준은 네 가지입니다.

1. **공정함**: 진 이유가 내 판단·조작에 있는가. 운으로 지면 다시 하지 않는다.
2. **선택**: 매 순간 고를 만한 위험과 보상이 있는가(빠른 길 vs 안전한 길).
3. **손맛**: 입력·성공·실패에 즉시, 분명한 시각·소리 반응이 있는가.
4. **읽기 쉬움**: 판의 경계·위험·남은 시간을 한눈에 알 수 있는가.

## 디자인 원칙

화면에는 **게임에 필요한 요소만** 그립니다. 풍경·삽화 같은 장식(도시, 달, 구름, 언덕, 색종이, 화면 번쩍임)은 넣지 않습니다. 움직임은 상태가 바뀌었다는 것을 알려 줄 때만, 짧고(0.2~0.35초) 부드러운 감속 곡선으로 씁니다. 흔들림은 최대 3px, 고리는 1.5px 선 하나로 제한하고, 움직임 줄이기 설정에서는 모두 꺼집니다.

## 이번에 고친 것

| 게임 | 연구 결과(문제) | 반영 |
|---|---|---|
| 지뢰찾기 | 무작위 배치라 중·고급에서 정보만으로 풀 수 없는 50:50이 자주 생김. 실력과 무관하게 지는 판이 반복되어 이탈의 주원인 | **추측 없는 판** 생성: 첫 클릭 3×3을 비운 뒤, 논리 풀이기(단일 숫자·부분집합·남은 지뢰 수)로 끝까지 풀리는지 검사. 막히면 경계 지뢰를 미탐색 영역으로 옮겨 다시 검사. 고급 24×16·99개도 평균 수십 ms. 누른 곳에서 퍼지는 물결 열기, 폭발 시 판 흔들림과 지뢰가 차례로 드러나는 연출 |
| 스네이크 | 격자 점이 흐려 칸과 판 경계를 읽기 어려움. 클래식은 벽이 보이지 않아 ‘어디서 죽는지’ 예측 불가. 먹이만 반복되어 선택이 없음 | 명도 차가 분명한 체크무늬 칸 + 옅은 칸 선, 경계는 한 줄 테두리로만 표시(클래식·고속 **붉은 실선** = 닿으면 끝, 경계 통과 **초록 점선** = 이어짐). 먹이 5개마다 6초 동안 **노란 보너스**(남은 시간 고리, 빨리 먹을수록 +30~80점)로 위험한 우회 선택을 만듦. 속도는 먹은 개수로만 오름. 먹이는 부드럽게 커지며 나타나고, 삼킨 먹이가 몸을 타고 내려감 |
| Endless Runner | 코인은 먹든 말든 큰 차이가 없음. 점프에 무게감이 없음 | **코인 연속** 배수(최대 ×5): 놓치면 끊겨 코인 경로를 따라갈 이유가 생김. 오를 때 살짝 늘어나고 착지 때 잠깐 납작해지는 스쿼시·스트레치, 코인의 가벼운 떠오름 |
| 플래피 | 통과·충돌 순간의 반응이 약함 | 통과 시 얇은 고리, 충돌 시 작은 흔들림 |
| Stack Tower | 잘린 부분과 PERFECT가 잘 보이지 않음 | 잘린 조각이 천천히 회전하며 사라짐, PERFECT 때 얇은 고리(3연속부터 노란색) |
| 테트리스 | 줄 제거가 즉시 사라져 무엇이 지워졌는지 놓침 | 지운 줄이 0.35초 동안 얇아지며 사라지는 잔상, 착지 블록의 옅은 반짝임(판정은 그대로 즉시) |
| 벽돌깨기 | 아이템이 2종(확장·생명)뿐 | **» 관통 공**(6초간 벽돌을 뚫음, 공이 붉게 바뀜) 추가, 깨진 벽돌은 제자리에서 작아지며 사라짐 |
| 카드 짝맞추기 | 실패가 조용히 덮여 무엇을 틀렸는지 남지 않음 | 카드 뒤집기, 짝 성공 시 살짝 커졌다 돌아옴, 실패 시 붉은 테두리와 작은 좌우 흔들림 |
| Asteroids · Invaders · Catch · Dodge · Tanks · 땅따먹기 | 피격이 파티클 몇 개뿐이라 놓치기 쉬움 | 생명 감소·격파 순간에 작은 흔들림(최대 3px)과 얇은 고리 |
| 전체 | 결과창이 갑자기 나타남. 0점 판도 ‘최고 기록’으로 표시 | 결과 카드가 아래에서 살짝 떠오르며 나타남. 점수형 기록은 0점이면 최고 기록으로 치지 않음 |

공용 효과(`js/effects.js`)는 판정과 무관하며 입자 수에 상한이 있고, 움직임 줄이기 설정에서는 모두 꺼집니다.

## 검사

`tests/fun.mjs`: 세 난이도 125판이 모두 추측 없이 풀리는지(지뢰 수·첫 클릭 안전 포함), 풀이기가 진짜 50:50을 ‘풀 수 없음’으로 판단하는지, 첫 클릭이 3×3 이상 여는지, 스네이크 벽 충돌·포털 통과, 효과 모듈의 유한 좌표·수명 만료를 확인합니다. 브라우저 검사는 40종과 컴퓨터 모드를 실제 Chromium에서 실행해 콘솔 오류가 없는지 봅니다.
