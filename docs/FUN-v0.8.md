# 재미 연구와 개선 · v0.8

40종을 직접 실행해 보며 “다시 하고 싶게 만드는 요소”를 기준으로 살폈습니다. 판단 기준은 네 가지입니다.

1. **공정함**: 진 이유가 내 판단·조작에 있는가. 운으로 지면 다시 하지 않는다.
2. **선택**: 매 순간 고를 만한 위험과 보상이 있는가(빠른 길 vs 안전한 길).
3. **손맛**: 입력·성공·실패에 즉시, 분명한 시각·소리 반응이 있는가.
4. **읽기 쉬움**: 판의 경계·위험·남은 시간을 한눈에 알 수 있는가.

## 이번에 고친 것

| 게임 | 연구 결과(문제) | 반영 |
|---|---|---|
| 지뢰찾기 | 무작위 배치라 중·고급에서 정보만으로 풀 수 없는 50:50이 자주 생김. 실력과 무관하게 지는 판이 반복되어 이탈의 주원인 | **추측 없는 판** 생성: 첫 클릭 3×3을 비운 뒤, 논리 풀이기(단일 숫자·부분집합·남은 지뢰 수)로 끝까지 풀리는지 검사. 막히면 경계 지뢰를 미탐색 영역으로 옮겨 다시 검사. 고급 24×16·99개도 평균 수십 ms. 누른 곳에서 퍼지는 물결 열기, 폭발 시 판 흔들림과 지뢰가 차례로 드러나는 연출 |
| 스네이크 | 격자 점이 흐려 칸과 판 경계를 읽기 어려움. 클래식은 벽이 보이지 않아 ‘어디서 죽는지’ 예측 불가. 먹이만 반복되어 선택이 없음 | 명도 차가 분명한 체크무늬 칸 + 칸 선, 클래식·고속은 **붉은 벽돌 벽**, 경계 통과는 **움직이는 초록 점선 포털**. 먹이 5개마다 6초 동안 **황금 별**(빨리 먹을수록 +30~80점)로 위험한 우회 선택을 만듦. 속도는 먹은 개수로만 올라 보너스 때문에 갑자기 빨라지지 않음. 사과·눈·혀·삼킨 먹이가 몸을 타고 내려가는 연출, 충돌 시 흔들림·번쩍임 |
| Endless Runner | 단색 배경에 사각형만 있어 속도감이 약함. 코인은 먹든 말든 큰 차이가 없음 | 별·달·두 겹 도시의 시차 스크롤, 달리는 다리·착지 먼지·속도선. **코인 연속** 배수(최대 ×5): 놓치면 끊겨 코인 경로를 따라갈 이유가 생김 |
| 플래피 | 배경이 비어 진행감이 약함 | 구름·두 겹 언덕 시차 스크롤, 통과 고리, 10개마다 축하, 충돌 흔들림 |
| Stack Tower | 높이가 올라가도 화면 변화가 없음 | 높이에 따라 하늘이 저녁→밤→별빛으로 변함, 블록 측면 음영, 잘린 조각이 회전하며 떨어짐, PERFECT 충격파(3연속부터 노란 고리와 흔들림) |
| 테트리스 | 줄 제거가 즉시 사라져 쾌감이 약함 | 지운 줄의 흰 잔상, 착지 블록 반짝임, TETRIS 때 화면 번쩍임·흔들림·충격파(판정은 그대로 즉시) |
| 벽돌깨기 | 아이템이 2종(확장·생명)뿐 | **✹ 불꽃 공**(6초간 벽돌 관통) 추가, 부서진 벽돌 조각이 튀어 떨어짐, 아이템 부유·후광 |
| 카드 짝맞추기 | 실패가 조용히 덮여 무엇을 틀렸는지 남지 않음 | 3D 뒤집기, 짝 성공 빛 번짐, 실패 시 붉은 테두리 흔들림과 낮은 소리 |
| Asteroids · Invaders · Catch · Dodge · Tanks · 땅따먹기 | 피격이 파티클 몇 개뿐이라 놓치기 쉬움 | 공용 효과에 **흔들림·번쩍임·충격파** 추가, 생명 감소·격파 순간에 적용 |
| 전체 | 이겨도 결과창이 담담함. 0점 판도 ‘최고 기록’으로 표시 | 승리·최고 기록 때 결과창 **색종이**(움직임 줄이기 설정 존중). 점수형 기록은 0점이면 최고 기록으로 치지 않음 |

공용 효과(`js/effects.js`)는 판정과 무관하며 입자 수에 상한이 있고, 움직임 줄이기 설정에서는 모두 꺼집니다.
